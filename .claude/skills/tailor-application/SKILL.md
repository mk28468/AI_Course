# Tailor Application

## Step 1 — Extract requirements
Read the posting and list every requirement as a separate row. Include implicit
requirements (enrollment status, location, timing) as well as stated ones.

## Step 2 — Build the evidence map
For each requirement, record a table row:

| Requirement | Evidence (verbatim quote + file) | Strength |

Strength is one of:
- **direct** — the candidate did this exact thing, and a line says so
- **adjacent** — related work that a reader must extrapolate from
- **none** — nothing in the career files supports this

Quote source lines verbatim. If you cannot quote a line, the strength is **none**.
Never paraphrase a line into a stronger claim than it makes.

## Step 3 — Pick the stories
Choose stories only where strength is **direct** or the strongest **adjacent**
evidence available. Name the file and line each story comes from.

## Step 4 — Report the gaps
List every **none** row explicitly. Do not soften them and do not fill them with
plausible-sounding experience.
